## Оптимизация
Launcher/splash/action/navigation icon ассеты — XML/vector. Bitmap внутри приложения ограничены семью оптимизированными WebP: app background 720x1280 весом 10 KB, onboarding 840x500 весом 17 KB, home 720x405 весом 32 KB, level 720x405 весом 40 KB, action panel 720x240 весом 5 KB, victory result 720x405 весом 22 KB и defeat result 720x405 весом 21 KB. Google Play high-res icon хранится отдельно в `play-assets`, поэтому не увеличивает размер приложения. Размер release `.aab` после shrink — около 2.6 MB. Release validation блокирует регрессии: AAB <= 8 MiB, debug APK <= 25 MiB, in-app WebP total <= 256 KiB, один WebP <= 96 KiB, без audio/video/custom font resources.
